# 产品与界面设计

Let’s Do 是个人任务工具。想起一件事时可以只写标题，有需要再安排到某周或某天。平时从「今天」或桌面小组件看接下来要做什么，在日历里调整安排，在「待办」里找齐还没做完的事。

这里记录现行源码采用的设计及其理由。实测范围见[当前验证边界](DEVELOPMENT.md#当前验证边界)和 [Mac 分发验收](MAC-DISTRIBUTION.md#候选资产验收)。

## 设计取舍

- **先看到任务，再看到操作。** 清单和小组件优先显示标题，备注、具体时刻和更多操作按需要出现。可由所在日期看懂的信息少重复，辅助功能仍能读到完整名称和动作。
- **让日常路径短一些。** 打开应用就能处理今天的事，从今天到日历顺手相邻。回顾完成和恢复删除各有清晰入口。增加入口前，先看它是否对应一个独立而经常发生的操作。
- **保持克制的原生界面。** 复用现有组件和排版，用对齐、间距、细分隔线和选中态表达层级。选中态沿用系统反馈。清单允许长标题换行，摘要在有限空间内截断并提供完整入口。键盘、触控和辅助功能与视觉一起核对。共享配色见 [AppStyle](../Shared/AppStyle.swift)。

Microsoft To Do 与滴答清单用来比较「当前要做什么」「何时做」「如何回看」这几种路径。Let’s Do 的界面围绕自己的记录、按周安排和桌面查看流程取舍。

## 任务、时间与状态

「待办」表示所有未删除、未完成的任务。日期或周归属是任务上的安排，同一条任务可以同时出现在待办、今天或日历。查看、改期和完成始终针对原任务，详情和链接复用同一个任务 UUID。

| 安排 | 在哪里看到 | 时间过去后仍未完成 |
|---|---|---|
| 未定日期也未定周 | 在待办的「未安排」分组。快速记和手动导入使用这一安排。自动导入取原提醒截止日，无有效日期时留空 | 继续留在待办，等用户选择日期或周 |
| 只指定一周 | 在该周的「本周待安排」和待办里查看，可再排进具体某天 | 整周结束后进入今天的「此前未完成」，并可从之后周次的「往周未完成」回看 |
| 单日、跨日或带时段 | 在计划实际覆盖的日期显示。覆盖今天的未完成任务进入今天 | 日期区间结束后进入今天的「此前未完成」。原计划仍在原日期，只有用户明确改期才更新 |

例如周一安排的任务到周三仍未完成，今天页会提示它，周历里仍留在周一。零点结束的跨日任务只计到前一天。日期覆盖和跨日判断复用 [共享日期规则](../Shared/Scheduling.swift)与 [TodayTasks](../Shared/TodayTasks.swift)。

「待办」按安排分为「此前未完成」「今天」「本周」「以后」「未安排」，只显示有任务的分组。前两组沿用今天页的规则，「本周」包括本周其余日期和本周待安排，周待安排排在本周各日之后。分组只是阅读视图，不改动原计划。日期与周归属都为空的任务归入「未安排」。勾选完成后可在「已完成」按实际完成时间回看，也能设回未完成。主动删除的任务进入「回收站」，恢复时保留原安排与完成状态。分组规则见 [TodoSections](../Shared/TodayTasks.swift)。

## 导航与平台布局

主窗口默认进入「今天」。今天页显示当天安排和可展开的「此前未完成」，日期规划集中在独立的「日历」。从待办可以直接查看或安排任意未完成任务。主空间按标题搜索待办和已完成任务，回收站内按标题搜索已删除任务。

侧栏依次是「今天」「日历」「待办」。「已完成」「回收站」位于细分隔线下，和上方一样单击直达。未选中时用中性色图标，文字保持清楚，选中沿用系统高亮。分隔线是装饰，键盘和辅助功能只经过任务入口。

Mac 侧栏用组间留白和细线表达主次，五项标题共用字号与字重，行高和图标对齐，设置在侧栏底部。日历选中的日期与今天页的实际日期独立，切回日历时保留日期和周／月视图。入口与窗口布局见 [MainView](../App/MainView.swift)。

## 记录、改期与详情

### 记录

| 情况 | 处理 |
|---|---|
| 在「今天」或「待办」底部输入 | 按回车添加。今天页默认安排今天，待办默认未安排 |
| 从日历或小组件「快速记」新建 | 日历采用选中或点击的日期，小组件快速记默认未安排 |
| 在「本周待安排」新建 | 默认使用正在查看的周 |
| 已有草稿时切换入口 | 保留草稿和用户选过的安排。入口默认值只用于新输入 |
| 标题开头或结尾有日期 | 建议相应安排，保留原文。支持今天、明天、后天、周五、下周一、周末、本周／下周、11月20日、11/20 等写法 |
| 标题含「上周五」「每周五」等未支持的说法 | 保留标题，使用入口默认安排或草稿已有的选择 |
| 识别出日期 | 底部输入框提示「添加到…」，完整新增在日期行显示建议 |
| 点「不按标题安排」 | 回到当前入口的默认安排，仅对当前草稿生效 |
| 用户已经选择日期 | 保留用户选择，停止标题识别。恢复草稿时保留建议来源 |
| 主应用运行时从其他应用记录 | `⌃⌥N` 或应用菜单的「快速记录」打开独立窗口，默认未安排。快捷键可在设置中关闭，遇到占用或启用失败时在设置中提示 |
| 在完整新增和独立快速记之间切换 | 共用内容、计划和任务标识，同一时间只由一个完整编辑器接手 |
| 保存任务 | 成功后清理草稿，失败时保留输入并显示提示 |

草稿和标题日期识别见 [CaptureDraft](../App/CaptureDraft.swift)，完整新增和独立快速记见 [QuickCaptureView](../App/QuickCaptureView.swift)。

### 改期

未安排任务可从待办详情选日期，也可先「放入本周待安排」。日期面板优先提供快捷日期和单日点选。已有任务的快捷日期、单日选择和取消安排即时提交，新建时只更新草稿。周归属和跨天先在面板内编辑，再显式点「应用」。折叠进阶选项后保留应用入口。浏览月份只改变面板显示，关闭面板时放弃尚未应用的安排，正文沿自己的保存流程提交。写入失败时保留面板与重试信息。拖动日历任务保留原跨度，明确选「安排到今天」则设为单日。编辑标题或正文时继续保留已有时段。实现见 [ScheduleFields](../App/ScheduleFields.swift)。

### 详情

从标题和正文开始，日期使用紧凑控件，删除放在底部，版本与完成等操作收在更多菜单。清单保留直接完成。Mac 以同一个右侧抽屉承接详情和完整新增，抽屉贴齐内容区的上下边缘，用系统半透明材质和向左的软阴影交代层级，主内容与侧栏保留原有位置。抽屉短距离滑入或收回，系统开启「减少动态效果」时改用短淡入淡出。在抽屉清单内打开任务或新建时，保持抽屉位置，收起编辑器后回到清单。输入过程只写本机草稿，供退出或重启后继续编辑；收起详情、切换任务或返回时自动保存一次，形成一个不可变正文版本，`⌘↩` 可立即保存。恢复的旧草稿标题与任务不同时不自动保存，由用户在保存时选择标题；标题为空或任务已进回收站时也只保留草稿。从外部点击、关闭按钮或 Escape 收起 Mac 编辑器时，先结束原生输入并核实草稿落盘，草稿写入失败时保留编辑器与错误；任务保存失败则提示错误并保留草稿，下次打开时恢复。输入法与日期／历史弹层先处理各自的退出。编辑与保存规则见[数据规则](DEVELOPMENT.md#数据规则)、[TaskDetailView](../App/TaskDetailView.swift) 和 [TaskWritingEditor](../App/TaskWritingEditor.swift)。

## 日历与桌面小组件

**日历用于规划。** Mac 的日历控件集中在一行工具栏。左侧依次放「周／月」、日期范围和前后翻页，「回到今天」只在选中其他日期时出现。右侧的「待安排」打开当前周的清单，放大镜按需展开搜索框。周历从周一排到周日，日期头、跨日条和任务区按列对齐，鼠标悬停时整列淡染。空间不足时保留可读列宽并允许横向滚动。Mac 日历、任务清单和抽屉使用原生浮动滚动条，滚动条不占网格或正文宽度。点日期数字或溢出数量会在右侧查看当天任务，点日期格空白处直接按该日新建。拖动已安排任务可以改期并保留原跨度。实现见 [WeekView](../App/WeekView.swift) 和 [MonthView](../App/MonthView.swift)。

**小组件用于一瞥和直达。** WidgetKit 决定各尺寸的可用空间，应用按尺寸分配标题行数。组件优先展示可执行的任务和清晰的日期，更多内容通过数量、日期或标题打开应用。任务标题定位原任务，圆圈提交完成，「快速记」打开记录界面。

| 桌面小组件 | 摘要与入口 |
|---|---|
| 今天的任务 | 小号最多一条，有此前未完成时优先显示最近一条。中号最多两条，两类都有任务时各留一条。今天和此前均无待办时，可在空态下预览未来七天内最近的一项有日期任务。`+N` 打开应用的「今天」并展开「此前未完成」。页脚「待办」打开待办清单 |
| 本周计划中号 | 标题与周范围放在顶栏，正文按日期分组，每组日期只写一次。先给本周已过日期、今天和后续安排留代表任务，普通状态最多四条，有读取提示时最多三条。有余量再露出周待安排或补齐更多任务。标题打开周历，日期组的日期和 `+N` 打开当天清单。「待安排」组打开该周待安排清单。存在往周未完成时，页脚显示相应入口 |
| 本周计划大号、宽版 | 按七天展示，未完成的任务排在已完成之前。大号每个日期最多一条，宽版每列最多两条，更多任务通过 `+N` 打开。周待安排另有入口 |
| 月历总览 | 先看日期分布，再通过日期打开相应清单。组件内的今天摘要沿用今天页的日期规则 |

中号周摘要中，跨日任务只显示一次标题和原计划范围。覆盖今天时归今天组，已结束时归最后覆盖日，未来任务按首个覆盖日分组。每天的总数按实际覆盖计算，`+N` 只算覆盖该日且摘要里未露出标题的任务。周总数按任务 UUID 去重，包含本周待安排。有任务却没分到摘要行的日期用轻量入口承接，横向放不下时合并为「另有 N 天待办」，进入周历。「本周待安排」与「往周未完成」按组件所显示周的周一定位。

组件要区分无安排、已完成和读取或会话异常。完成操作在任务写入本机库后反馈成功。摘要保留完整任务的辅助功能标签及原任务入口。布局与入口见 [WidgetCalendarView](../Shared/WidgetCalendarView.swift)、[WeekTaskOverview](../Shared/WeekTaskOverview.swift) 和 [AppDestination](../Shared/AppDestination.swift)。

组件预览用于查看布局。系统放置、跳转、完成落库和时间线刷新按[候选资产验收](MAC-DISTRIBUTION.md#候选资产验收)分别验证。
