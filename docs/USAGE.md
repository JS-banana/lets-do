# 使用 Let’s Do

## 安装与首次打开

从项目发行页下载 Mac 版 DMG。打开 DMG，将 Let’s Do.app 拖到「应用程序」，再从那里打开。[下载 Mac 版](https://github.com/JS-banana/lets-do/releases/latest)

Mac 预览版尚未经过 Apple 公证。首次打开被系统拦截时，前往「系统设置 → 隐私与安全性」，选择「仍要打开」。[Apple 操作指引](https://support.apple.com/zh-cn/102445)

## 记下一件事

在「待办」底部输入标题，按回车添加。暂时不选日期也可以，之后打开任务再补备注和安排；修改会在收起详情时自动保存。「待办」汇总所有未完成任务，按「此前未完成」「今天」「本周」「以后」「未安排」分组。`⌘N` 打开详细新建，`⌘↩` 提交；`⌘⇧N` 可以新建主窗口。

在任何记录入口，标题开头或结尾写上日期，会自动安排到那天，例如「明天买菜」「周五交报告」「下周一开会」「11月20日体检」；「本周」「下周」会放进对应周的待安排。标题保持原样，输入框下会显示「添加到…」，点「不按标题安排」即可取消。

在其他应用里也能记：Let’s Do 运行时按 `⌃⌥N` 打开快速记录窗口，输入后保存即可。不需要时可在「设置 → 快速记录」关闭。

## 安排与回顾

任务可以安排到某一天、连续几天，或先放进某一周的「本周待安排」。在任务的日期选项里选择「放入本周待安排」，以后再决定具体日期。

日历可以切换周历和月历。点击日期查看当天任务，拖动已有任务可以改期。跨日任务拖动后保留原来的跨度。

「今天」会显示当天安排，以及此前已安排但还没完成的事。错过日期不会自动改动原计划，你可以继续完成，也可以重新安排。

搜索按标题查找任务。已完成的任务可以回看，误删的任务可以从回收站恢复；任务详情中还可以查看正文历史。

## 添加桌面小组件

安装后先打开一次 Let’s Do，再在 Mac 桌面右键选择「编辑小组件」，搜索 Let’s Do。可以添加「今天的任务」「本周计划」或「月历总览」，选择适合桌面的尺寸。

点击任务旁的圆圈标记完成，点击标题或日期打开应用中对应的内容。「快速记」会打开记录窗口，输入后保存。小组件空间有限，点击数量可以查看完整清单。

## 与手机上的提醒事项配合

暂无 iPhone 版，手机端使用 Apple 的「提醒事项」。两台设备登录同一 Apple 账户，在 iCloud 设置中开启「提醒事项」。可以在 iCloud 下建一份专用清单，选择时核对账户名和清单名。同名的本机清单只在这台 Mac 上可见。[Apple 设置指引](https://support.apple.com/guide/icloud/mmbf52194b5a/icloud)

**开启同步。** 在「设置 → 提醒事项」允许访问，选择「账户 · 清单」，打开「与提醒事项同步」。开启前可核对要新写入的 Mac 待办数和要导入的提醒数。新任务进入所选清单，已关联或曾从其他清单导入的任务继续在原清单核对。

- 在 Mac 新建、改名、安排到某天、完成或重开任务，对应提醒会更新。未安排与周待安排没有截止日，跨日任务使用开始日。将任务移入回收站会删除已同步的提醒，恢复未完成任务后会重新同步。
- 在所选清单新建普通提醒，它会带着标题、纯文本备注和截止日期进入 Let’s Do。带时刻的提醒在 Mac 上只安排到当天，手机保留原时刻。后续编辑的正文、备注和闹钟各自保留。
- 手机上勾选已关联的提醒会完成 Mac 任务。手机改名、改日期、取消勾选或删除提醒，Mac 保留原任务。某条提醒被删除或复制后，可在对应未完成任务的「更多 → 提醒事项同步待核对…」核对，再决定是否重新同步。
- 带其他链接和重复的提醒可在「待办」里手动导入。带链接的提醒保留原链接。重复提醒只复制成 Mac 任务，在 Mac 完成或回收它都保留原系列。

同步需要 Let’s Do 在 Mac 上运行，退出后积累的变化会在下次打开时处理。切换清单会暂停同步，需要在设置中重新开启。关闭开关会停止自动导入和推送，已关联提醒的手机完成仍会回写。重新开启时，暂停期间改动过的任务也会同步，包括回收对已同步提醒的删除。

**关闭同步时手动使用。** 在「待办 → 从提醒事项导入」选择事项，标题和备注会进入「未安排」。要把某项 Mac 待办带到手机，从任务详情的「更多 → 发送到提醒事项…」选择清单，可单独指定全天截止日。只手动导入的原提醒与 Mac 任务各自独立；明确发送或此前已关联的提醒可以回写完成。若权限被撤销，请到「系统设置 → 隐私与安全性 → 提醒事项」恢复后刷新。

## 备份与恢复

在「设置 → 数据」中导出 JSON 备份，并将文件保存到单独的位置。备份可能包含私人任务内容，请妥善保管。

恢复只支持空的本地任务库，不能合并或覆盖已有任务。JSON 备份包含任务和已保存的正文版本，但不包含未提交草稿、提醒事项关联等完整应用数据，恢复后需要重新选择提醒事项清单。遇到升级问题时，请先保留原有数据和备份，再反馈问题。

## 更新与反馈

在「Let’s Do → 检查更新…」查看正式新版，选择安装并重新打开。希望定期检查时，勾选同一菜单里的「自动检查更新」。如果菜单里没有更新入口，或发行说明要求手动安装，请先按该版说明备份数据，再退出应用，将新版 DMG 中的应用拖到「应用程序」并选择「替换」。[发行记录](https://github.com/JS-banana/lets-do/releases)

反馈问题时，请说明应用版本、macOS 版本、操作步骤和实际结果。截图前遮住私人内容，不要上传个人任务库。[提交 Issue](https://github.com/JS-banana/lets-do/issues)
