# 使用 Let’s Do

这里介绍 Mac 预览版 v0.3.1 的常用操作。下载入口和产品介绍见 [README](../README.md)，之后的版本变化以[发行记录](https://github.com/JS-banana/lets-do/releases)为准。

目前提供 Mac 下载版，手机端可通过 Apple 提醒事项配合使用；独立的 iPhone 客户端仍在开发中。

## 记下一件事

在「待办」底部输入标题，按回车添加。暂时不选日期也可以，之后打开任务再补备注和安排。「待办」汇总所有未完成任务，没有日期的事项会标为「未安排」。`⌘N` 打开详细新建，`⌘↩` 提交；`⌘⇧N` 可以新建主窗口。

## 安排与回顾

任务可以安排到某一天、连续几天，或先放进某一周的「本周待安排」。在任务的日期选项里选择「放入本周待安排」，以后再决定具体日期。

日历可以切换周历和月历。点击日期查看当天任务，拖动已有任务可以改期。跨日任务拖动后保留原来的跨度。

「今天」会显示当天安排，以及此前已安排但还没完成的事。错过日期不会自动改动原计划，你可以继续完成，也可以重新安排。

搜索按标题查找任务。已完成的任务可以回看，误删的任务可以从回收站恢复；任务详情中还可以查看正文历史。

## 添加桌面小组件

安装后先打开一次 Let’s Do，再在 Mac 桌面右键选择「编辑小组件」，搜索 Let’s Do。可以添加「今天的任务」「本周计划」或「月历总览」，选择适合桌面的尺寸。

点击任务旁的圆圈标记完成，点击标题或日期打开应用中对应的内容。「快速记」会打开记录窗口，输入后保存。小组件空间有限，点击数量可以查看完整清单。

## 与手机上的提醒事项配合

这项功能使用 Apple 的「提醒事项」。两台设备需要登录同一 Apple 账户，并在 iCloud 设置中开启提醒事项。可以先创建一份专用清单，方便区分要交给 Let’s Do 安排的事情。参见 [Apple 设置指引](https://support.apple.com/guide/icloud/mmbf52194b5a/icloud)。

**手机记录，Mac 安排。** 在 iPhone 的提醒事项里新建事项，等它出现在 Mac 的提醒事项中，再打开 Let’s Do 的「待办 → 从提醒事项导入」。授权后选择清单和要导入的事项。导入保留标题和纯文本备注，日期需要在 Let’s Do 中重新安排；原提醒中的重复、附件、子任务和闹钟不会一起导入。

**把某条任务带到手机。** 在 Mac 打开任务详情，从「更多」选择「发送到提醒事项」，选定清单。手机勾选这条已发送的提醒后，Mac 应用读取到变化时会完成原任务。如果 Mac 应用已经退出，需要重新打开，并等待系统提醒事项同步到本机。

这不是两个应用之间的完整双向同步：只有从 Let’s Do 明确发送的任务才接收完成状态；只导入过的原提醒，在手机勾选不会完成 Mac 中的任务。标题、正文、计划、删除和取消完成也不会双向同步。无需安装 iPhone 版 Let’s Do。

如果需要恢复授权，在「系统设置 → 隐私与安全性 → 提醒事项」中检查 Let’s Do 的权限。技术实现和验证范围见[提醒事项说明](MAC-REMINDERS.md)。

## 备份与恢复

在「设置 → 数据与诊断」中导出 JSON 备份，并将文件保存到单独的位置。备份可能包含私人任务内容，请妥善保管。

恢复只支持空的本地任务库，不能合并或覆盖已有任务。JSON 备份包含任务和已保存的正文版本，但不包含未提交草稿、提醒事项关联等完整应用数据，不能替代完整的旧版本数据迁移。遇到升级问题时，请先保留原有数据和备份，再反馈问题。

## 安装或使用遇到问题

当前 Mac 预览版尚未经过 Apple 公证。首次打开若被系统拦截，先尝试打开应用一次，再到「系统设置 → 隐私与安全性」选择「仍要打开」。请从[项目发行页](https://github.com/JS-banana/lets-do/releases/latest)下载；Apple 的具体步骤见[打开无法验证开发者的应用](https://support.apple.com/zh-cn/102445)。

仍有问题时，可以[提交 Issue](https://github.com/JS-banana/lets-do/issues)，说明应用版本、macOS 版本、操作步骤和实际结果。截图前遮住私人内容，不要上传个人任务库。
